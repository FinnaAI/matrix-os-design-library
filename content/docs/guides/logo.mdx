This guide decides how the Matrix rabbit appears: which look, what size, how much clear space, and when not to use it at all. It applies to product screens, app icons, launch screens and marketing. The mark itself, its files and the full icon specs are on [Logo](/library/foundations/logo).

## Ask one question: where will the rabbit sit?

| If it sits… | Look | Classes |
|---|---|---|
| On a product screen (nav, sign-in, empty state) | **Forest**, the default: teal-800 on the light surface | `text-teal-800` |
| As an app icon, favicon or Mac icon | **Sentinel**: near-white on Forest | `bg-teal-800 text-neutral-25` |
| On a launch screen | **Forest** in light mode, **Sentinel** in dark mode | `bg-neutral-25 text-teal-800` / `bg-teal-800 text-neutral-25` |
| In marketing (store, banner, social, print) | One of the four **marketing pairs** | see below |
| In place of an action icon (send, run, new) | **None.** Use a [Lucide icon](/library/foundations/iconography) | |
| For an agent | **None.** Agents get the mascot, not the mark | |

If you're not sure, it's Forest. Sentinel is for app icons and the dark launch screen; Signal is for marketing.

## Use the canonical mark, never a copy

Render `RabbitMark` from `components/brand/rabbit-mark.tsx`, or use the downloaded SVG from the Logo page. Don't trace it, rebuild it in another tool or keep a private copy in your app: copies drift (a cropped viewBox, an extra offset) and nobody notices until the icon looks wrong.

## Size by height, never by width

The mark is taller than it is wide (510:660). Set the height and let the width follow:

```tsx
<RabbitMark className="h-6 w-auto text-teal-800" />
```

Never set both height and width to fixed values, and never pass `preserveAspectRatio="none"`: that's how the rabbit gets squashed.

| Place | Height |
|---|---|
| Nav, toolbar | `h-5` (20px) |
| Page or panel header | `h-6` (24px) |
| Sign-in, dialog | `h-8` (32px) |
| Empty state | `h-12` (48px) |
| Brand moment (onboarding, marketing) | `h-16` (64px) or more |

**Never smaller than 16px** (`h-4`). This minimum is `PROVISIONAL`.

## Give it one ear-width of room

Keep empty space equal to **1/8 of the mark's height** on every side, rounded up to the spacing scale: `p-1` up to 32px, `p-1.5` up to 48px, `p-2` at 64px, `p-4` at 128px. No text, edge or other mark inside that space.

## One rabbit means Matrix

The rabbit stands for Matrix itself. Show it once per view. Several rabbits are only for agents, tasks or parallel work, and those use the mascot (its own component, coming later), not the mark. Avatar is for people only.

Keep the rabbit elegant and alert: no face, no speech bubble, no personality line next to it.

## Change nothing about the mark

Don't stretch, squash, rotate, outline, crop, simplify or push it off-centre. Don't add glows, blend modes or transparency to the rabbit. Don't color it outside the brand scales. This holds for small sizes too: the Android notification icon uses the full rabbit.

## App icons are flat Sentinel tiles

Every app icon is a near-white rabbit on a solid teal-800 tile, at about 66% of the tile's height and centred, with no offset or extra scale. iOS uses the same icon in light and dark. Android needs three layers: the background color, the rabbit, and a monochrome rabbit for themed icons (Android 13+). Full sizes and file names are on [Logo](/library/foundations/logo#app-icons).

## Marketing uses four pairs, nothing else

Marketing (store screenshots, banners, social, print) uses three colors: Forest (`teal-800`), Wheat (`gold-300`) and near-white (`neutral-25`), always in one of these pairs:

| Rabbit or wordmark | Background | Classes |
|---|---|---|
| near-white | Forest | `bg-teal-800 text-neutral-25` |
| Wheat | Forest | `bg-teal-800 text-gold-300` |
| Forest | Wheat | `bg-gold-300 text-teal-800` |
| Forest | near-white | `bg-neutral-25 text-teal-800` |

Don't put the rabbit on other brand colors, tints or photos, and don't pair near-white with Wheat (1.6:1, the rabbit fades). The wordmark "Matrix OS" follows the same pairs. See them side by side on [Logo](/library/foundations/logo#marketing-pairs).

## Accessibility

`RabbitMark` is hidden from screen readers. When it's the only content of a link or button, put the name on that element: `aria-label="Matrix OS home"`. When it stands for the brand on its own, wrap it in `<span role="img" aria-label="Matrix OS">`. Logos are exempt from contrast rules, but every approved look clears 3:1 anyway.
