---
title: Avatar
description: A circular identity for a person. A photo when there is one, otherwise initials, otherwise an icon. Agents are shown with the mascot, not an avatar.
---

## Usage

```bash
pnpm dlx shadcn@latest add avatar
```

Then replace `components/ui/avatar.tsx` with the [Matrix version](https://github.com/sahar-nouri-1/Matrix_design-system/blob/main/components/ui/avatar.tsx). It keeps shadcn's parts and adds sizes, initials from a name and the icon fallback.

```tsx
import { Avatar, AvatarFallback, AvatarImage } from '@/components/ui/avatar';

// Pass a name: it becomes the label screen readers announce and the fallback initials.
<Avatar name="Olivia Rhye">
  <AvatarImage src={user.photoUrl} alt="" />
  <AvatarFallback />
</Avatar>
```

The default is the person's photo. Always include `AvatarFallback` too: it shows the initials while the photo loads and whenever there isn't one (see Fallback). Avatars are for people. Agents aren't avatars: they're shown with the Matrix mascot, a separate component.

Every avatar in a group shares one size; give `AvatarGroupCount` the same `size`. Each avatar gets a ring in the page color so the overlap reads clearly.

## Behavior

#### The fallback is a cascade

The image loads over the fallback. While it loads, or if the address is broken, people see initials, never an empty circle that later jumps.

#### Initials stop at two

First word plus last word: "Mary Jane Watson" is **MW**. Emoji and accented letters are never cut in half. Use `getInitials(name)` if you need the same letters elsewhere.

#### The name is the label

With `name`, screen readers announce "Olivia Rhye", not "O R". Without a name (the icon fallback), add `role="img"` and an `aria-label`.

## API reference

<PropsTable
  type={{
    name: { type: 'string', description: 'Accessible label and the source of the fallback initials.' },
    size: { type: "'xs' | 'sm' | 'md' | 'lg'", default: "'md'", description: 'xs 20 · sm 24 · md 32 · lg 40.' },
    className: { type: 'string', description: 'Extra classes on the circle, e.g. a ring color.' },
  }}
/>

`AvatarImage` takes the usual `src` and `alt` (keep `alt=""` when `name` is set). `AvatarFallback` shows its children if you pass them, otherwise the initials, otherwise the icon. `AvatarBadge` and `AvatarGroupCount` take `className`; `AvatarGroupCount` and `AvatarSkeleton` also take `size`.

## Guidelines

<Guidelines>
  <Guideline>Always pass a `name`. Different initials make a list read as different people instead of a wall of identical icons.</Guideline>
  <Guideline>Use avatars for people only. Agents are shown with the mascot.</Guideline>
  <Guideline>Use `xs` (20px) in menus and dense lists, `md` or `lg` in rows, cards and chat.</Guideline>
  <Guideline>For several people, use a group with a few avatars and a +N chip, never one avatar and a number.</Guideline>
  <Guideline dont>Don't rely on the indicator color alone; say what it means in text nearby.</Guideline>
  <Guideline dont>Don't make avatars square or give them other colors; one consistent circle keeps people recognisable everywhere.</Guideline>
</Guidelines>
