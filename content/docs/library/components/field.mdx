import { Mail } from 'lucide-react';

## Usage

```bash
pnpm dlx shadcn@latest add field
```

Then replace `components/ui/field.tsx`, `label.tsx` and `separator.tsx` with the [Matrix versions](https://github.com/sahar-nouri-1/Matrix_design-system/tree/main/components/ui). They keep shadcn's parts and add the Matrix type, colors and spacing.

```tsx
import { Field, FieldDescription, FieldLabel } from '@/components/ui/field';
import { Input } from '@/components/ui/input';

<Field>
  <FieldLabel htmlFor="email">Email</FieldLabel>
  <Input id="email" type="email" placeholder="name@example.com" />
  <FieldDescription>We'll send the invite here.</FieldDescription>
</Field>
```

The spacing is part of the component: the **label sits 2px above** its control, **help text and errors 8px below** it, **16px between fields** and **24px between sections**. Validation timing and error copy follow the [Input behavior](/library/components/input#behavior).

## Required

<Example
  title="Asterisk after the label"
  code={`<Field>
  <FieldLabel htmlFor="email" required>Email</FieldLabel>
  <Input id="email" type="email" required placeholder="name@example.com" />
</Field>`}
>
  <Field className="max-w-sm">
    <FieldLabel htmlFor="required-email" required>
      Email
    </FieldLabel>
    <Input id="required-email" type="email" required placeholder="name@example.com" />
  </Field>
</Example>

`required` on the label adds the asterisk; set `required` on the control too, so browsers and screen readers know. The asterisk is neutral, not coral: coral means an error.

## Error

<Example
  title="Message below the control"
  code={`<Field>
  <FieldLabel htmlFor="email">Email</FieldLabel>
  <Input id="email" type="email" aria-invalid="true" aria-describedby="email-error" defaultValue="name@example" />
  <FieldError id="email-error">Enter a full email address, like name@example.com.</FieldError>
</Field>`}
>
  <Field className="max-w-sm">
    <FieldLabel htmlFor="error-email">Email</FieldLabel>
    <Input
      id="error-email"
      type="email"
      aria-invalid="true"
      aria-describedby="error-email-message"
      defaultValue="name@example"
    />
    <FieldError id="error-email-message">Enter a full email address, like name@example.com.</FieldError>
  </Field>
</Example>

Set `aria-invalid` on the control (coral border) and put the message in `FieldError`, linked with `aria-describedby`. The label stays neutral. `FieldError` also accepts an `errors` array from form libraries and shows each message once.

## API reference

Field is a set of small parts. Put a real control (Input, Input group, Textarea) inside; Field adds the label, help text, error and spacing.

## Guidelines

<Guidelines>
  <Guideline>Link every label to its control with `htmlFor` and `id`.</Guideline>
  <Guideline>Pair `FieldError` with `aria-invalid` on the control; never show an error with color alone.</Guideline>
  <Guideline>Use help text for what people need before they type (format, why it's needed), and the error for what went wrong.</Guideline>
  <Guideline>Mark required fields only when most fields are optional; if most are required, mark the optional ones instead.</Guideline>
  <Guideline>Just disable the control; the field softens its own label and help text.</Guideline>
  <Guideline dont>Don't add your own margins between fields; FieldGroup and FieldSet already space them.</Guideline>
</Guidelines>
