## Usage

```bash
pnpm dlx shadcn@latest add radio-group
```

Then replace `components/ui/radio-group.tsx` with the [Matrix version](https://github.com/FinnaAI/matrix-os-design-library/blob/main/components/ui/radio-group.tsx). It keeps shadcn's API (`value`, `onValueChange`, `defaultValue`) and adds the Matrix sizes and look.

```tsx
import { RadioGroup, RadioGroupItem } from '@/components/ui/radio-group';
import { Field, FieldLabel } from '@/components/ui/field';

<RadioGroup defaultValue="monthly" aria-label="Billing">
  <Field orientation="horizontal">
    <RadioGroupItem value="monthly" id="monthly" />
    <FieldLabel htmlFor="monthly">Monthly</FieldLabel>
  </Field>
  <Field orientation="horizontal">
    <RadioGroupItem value="yearly" id="yearly" />
    <FieldLabel htmlFor="yearly">Yearly</FieldLabel>
  </Field>
</RadioGroup>
```

The group handles the rest: one option selected at a time, one tab stop, arrow keys to move.

## Which control

| The list is… | Use | Why not the others |
| --- | --- | --- |
| 2–5 visible options, pick one | **Radio group** | Every option is readable at once, so people compare instead of search. |
| A long or searchable list, pick one | **Select** or combobox | A radio list you have to scroll stops being comparable. |
| Several independent options | **[Checkbox](/library/components/checkbox)** | A radio group can never mean "two of these". |
| A setting that applies immediately | **[Switch](/library/components/switch)** | Radios belong to a form that's saved. |
| Inside a dropdown menu | **Never a radio** | The menu owns the arrow keys; use a menu item with a check. |

## Behavior

#### The group is one tab stop

Tab enters the group once, on the selected option (or the first one). Arrow keys then move and select, skipping disabled options and wrapping at the ends.

#### Space selects; Enter doesn't

Enter is left for submitting the form.

#### Give the group a name

Label the group with a `FieldLegend` inside a `FieldSet`, or `aria-label` on `RadioGroup`, so screen readers announce what the choice is about.

## Guidelines

<Guidelines>
  <Guideline>Use radios for 2–5 options people should compare at a glance.</Guideline>
  <Guideline>Select a sensible default when one exists, so the group never starts empty without reason.</Guideline>
  <Guideline>Order options logically: most common first, or a natural order (small to large).</Guideline>
  <Guideline dont>Don't use a single radio on its own; it can't be unselected. Use a checkbox.</Guideline>
  <Guideline dont>Don't put radios inside a dropdown menu.</Guideline>
</Guidelines>
