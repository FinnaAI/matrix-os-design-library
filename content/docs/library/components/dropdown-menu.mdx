title: Dropdown menu
description: A button-triggered list of actions. One size, 32px rows with 14px text and icons; rows grow to 40px on touch.
---

## Usage

```bash
pnpm dlx shadcn@latest add dropdown-menu
```

Then replace `components/ui/dropdown-menu.tsx` and add `menu-styles.ts` from the [Matrix versions](https://github.com/FinnaAI/matrix-os-design-library/tree/main/components/ui). The menu card, rows, labels and dividers come from `menu-styles.ts`, which Select shares, so a menu and a select's options always look the same. Menus animate with `tw-animate-css`, shadcn's standard.

```tsx
import {
  DropdownMenu,
  DropdownMenuContent,
  DropdownMenuItem,
  DropdownMenuSeparator,
  DropdownMenuTrigger,
} from '@/components/ui/dropdown-menu';

<DropdownMenu>
  <DropdownMenuTrigger asChild>
    <Button variant="ghost" square aria-label="More options"><Ellipsis /></Button>
  </DropdownMenuTrigger>
  <DropdownMenuContent align="end">
    <DropdownMenuItem onSelect={rename}><Pencil /> Rename</DropdownMenuItem>
    <DropdownMenuItem onSelect={duplicate}><Copy /> Duplicate</DropdownMenuItem>
    <DropdownMenuSeparator />
    <DropdownMenuItem variant="destructive" onSelect={remove}><Trash2 /> Delete</DropdownMenuItem>
  </DropdownMenuContent>
</DropdownMenu>
```

A menu is for actions. To pick a value in a form, use a [Select](/library/components/select).

## Behavior

#### The keyboard is built in

Enter, Space or ArrowDown opens the menu; arrows move, typing jumps to a matching row, Escape closes and returns focus to the trigger.

#### Highlight, not a focus ring

Rows highlight in neutral on hover and with the arrow keys. The gold ring stays on the trigger, so a menu never fills with rings.

#### Rows don't wrap

Labels stay on one line. Keep them short (verb + noun); the menu grows to fit, up to the screen edge.

#### Touch grows the rows

On a touch screen rows grow from 32px to 40px, automatically.

## Guidelines

<Guidelines>
  <Guideline>Open menus from a button: an icon button (⋯) for row or card actions, a labelled button for a toolbar.</Guideline>
  <Guideline>Write rows as verb + noun ("Rename agent"); order them by how often they're used, with destructive actions last, after a divider.</Guideline>
  <Guideline>Give every row an icon or none; don't mix within a group.</Guideline>
  <Guideline dont>Don't use a menu to pick a value in a form; use a [Select](/library/components/select).</Guideline>
  <Guideline dont>Don't nest more than one submenu deep.</Guideline>
</Guidelines>
