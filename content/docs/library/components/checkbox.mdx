---
title: Checkbox
description: Turns one option on or off, or picks several from a list. Outlined, with a dark check when selected.
---

## Usage

```bash
pnpm dlx shadcn@latest add checkbox
```

Then replace `components/ui/checkbox.tsx` with the [Matrix version](https://github.com/FinnaAI/matrix-os-design-library/blob/main/components/ui/checkbox.tsx). It keeps shadcn's API (`checked`, `onCheckedChange`, `defaultChecked`) and adds the Matrix sizes and look.

```tsx
import { Checkbox } from '@/components/ui/checkbox';
import { Field, FieldLabel } from '@/components/ui/field';

<Field orientation="horizontal">
  <Checkbox id="terms" />
  <FieldLabel htmlFor="terms">I agree to the terms</FieldLabel>
</Field>
```

## Behavior

#### Space toggles; Enter doesn't

Space checks and unchecks, the same as a native checkbox. Enter is left for submitting the form around it.

#### Indeterminate is set from code

Use `checked="indeterminate"` for a "select all" box when only some items in the group are selected. Clicking it selects all.

## Guidelines

<Guidelines>
  <Guideline>Use a checkbox for choices saved with a form, consent ("I agree to the terms") and multi-select lists.</Guideline>
  <Guideline>Write labels as a positive statement of what checking does: "Send a weekly summary", not "Don't send emails".</Guideline>
  <Guideline>Link the label with `htmlFor` so clicking the text toggles the box.</Guideline>
  <Guideline dont>Don't use a checkbox for a setting that takes effect immediately; use a [Switch](/library/components/switch).</Guideline>
  <Guideline dont>Don't use checkboxes when only one option can be picked; use a [Radio group](/library/components/radio-group).</Guideline>
</Guidelines>
