---
title: Select
description: Picks one value from a short, known list. Click and pick, no typing. Looks and sizes like Input.
---

## Usage

```bash
pnpm dlx shadcn@latest add select
```

Then replace `components/ui/select.tsx` and add `menu-styles.ts` from the [Matrix versions](https://github.com/sahar-nouri-1/Matrix_design-system/tree/main/components/ui). The trigger matches [Input](/library/components/input) (border, sizes, focus, error) and the list matches [Dropdown menu](/library/components/dropdown-menu).

```tsx
import { Select, SelectContent, SelectItem, SelectTrigger, SelectValue } from '@/components/ui/select';

<Select value={frequency} onValueChange={setFrequency}>
  <SelectTrigger id="frequency"><SelectValue placeholder="Choose how often" /></SelectTrigger>
  <SelectContent>
    <SelectItem value="hourly">Every hour</SelectItem>
    <SelectItem value="daily">Every day</SelectItem>
    <SelectItem value="weekly">Every week</SelectItem>
  </SelectContent>
</Select>
```

If the list is long or people would rather type, use a combobox (coming later). If there are only 2–5 options that fit on screen, a [Radio group](/library/components/radio-group) is faster.

Sizes match Input and Button. shadcn's `size="default"` still works (same as `md`).

## Behavior

#### Opens below, at the trigger's width

The list sits under the trigger and is at least as wide as it; long option names make it wider. Keep option names short.

#### Keyboard

Space, Enter or the arrows open the list; arrows move, typing jumps to a matching option, Enter picks, Escape closes without changing anything.

#### Picking applies to the form

A select is a form value. If the change should apply immediately to a setting, that's still fine, but say so near the field.

## Guidelines

<Guidelines>
  <Guideline>Use a select for 5 to about 15 known options. Fewer: radio group. More, or searchable: combobox.</Guideline>
  <Guideline>Give it a visible label with [Field](/library/components/field).</Guideline>
  <Guideline>Pre-select a sensible default when one exists; use a placeholder only when people must actively choose.</Guideline>
  <Guideline dont>Don't use a select for actions; use a [Dropdown menu](/library/components/dropdown-menu).</Guideline>
</Guidelines>
