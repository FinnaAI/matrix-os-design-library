Matrix OS runs on many surfaces: the web shell, the desktop app, mobile, macOS and a family of built-in apps. This design system gives all of them **one set of tokens, one set of components and one set of rules**, so the product feels like a single, calm, capable computer.

## Source of truth

1. The approved Figma brand file (`Styles` page)
2. [`DESIGN.md`](https://github.com/HamedMP/matrix-os/blob/main/DESIGN.md) in the Matrix OS repository
3. This design system, which turns both into working tokens and components

When sources disagree, fix the lower level. Never create another token set.

## Principles

<Cards>
  <Card title="Expressive, not ornamental" description="Personality comes from type and color, never from decoration without purpose." />
  <Card title="Calm, not empty" description="Clear hierarchy and generous space keep people focused." />
  <Card title="Organic, not rustic" description="Rounded geometry and living colors that still feel precise." />
  <Card title="Technical, not intimidating" description="Machine information is legible and direct." />
  <Card title="Bright, not childish" description="Supporting colors are signals, not confetti." />
</Cards>
