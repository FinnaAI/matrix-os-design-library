title: Radius
description: Matrix is rounded but precise. Eight steps from a 2px corner to a full pill, chosen by the size of the element. Controls are 8px at every size; surfaces that hold them are 12px.
---

## Usage

```css
/* Radius is one property: border-radius, from a token. */
.panel {
  border-radius: var(--rounded-lg);
}
```

```tsx
// The same steps as Tailwind utilities
<div className="rounded-lg border border-border bg-card" />
```

shadcn components read `--radius`, which points at `--rounded-md` (8px), the control radius, so they pick up the Matrix default automatically.

## Radius follows size

<RadiusBySize />

A corner has to fit the element it rounds. The same 8px that looks right on a 36px button turns a 14px chip into a pill, and a 4px corner looks sharp on a large card. Before you pick a radius, check the height of the container and use the step next to it in the table. Between two rows, pick the smaller radius.

## Nested corners

<NestedRadius />

When a rounded surface sits inside another, the inner corner is the outer corner minus the gap between them. A 16px card with 8px padding holds 8px items. Matching radii make the inner corners look too round.

## Guidelines

<Guidelines>
  <Guideline>Use a token, never a hand-written `border-radius` or an arbitrary `rounded-[10px]`.</Guideline>
  <Guideline>Always consider the size of the container before picking a radius: small elements get small corners, large surfaces get larger ones.</Guideline>
  <Guideline>Controls (buttons, inputs, selects) are `md` (8px) at every size, so a row of them reads as one family. Their containers step up: `lg` for menus and popovers, `xl` for cards.</Guideline>
  <Guideline>Nest corners: inner radius = outer radius − padding.</Guideline>
  <Guideline>Use `full` only for pills and circles, never for rectangular buttons or cards.</Guideline>
  <Guideline dont>Don't mix radii on one surface (a rounded top with square bottom corners), except where it's attached to an edge.</Guideline>
  <Guideline dont>Don't round data tables or full-width bars; square edges read as structure.</Guideline>
</Guidelines>
