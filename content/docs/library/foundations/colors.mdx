title: Colors
description: Green is Matrix's brand tone, neutral drives action, coral warns of danger, teal confirms success and gold highlights. Every color on screen is a step of these brand scales; semantic tokens wrap the right step, so product code rarely reaches for a raw number.
---

## Usage

```css
/* Every color is a CSS custom property in styles/tokens.css.
   Prefer a semantic role; reach for a raw step only when no role fits. */
color: var(--muted-foreground);
background: var(--card);
border-color: var(--border);
```

```tsx
// The same roles as Tailwind utilities
<div className="border-border bg-card text-foreground" />
```

Every color has a CSS variable and a Tailwind class with the same name: `--card` is `bg-card`, `--muted-foreground` is `text-muted-foreground`. Swap the prefix for the property you're styling (`bg-`, `text-`, `border-`, `outline-`, `fill-`).

#### Cards separate by edge, not fill

The page (`--neutral-25`) and card (`--neutral-100`) surfaces are close in value, so a card never relies on its fill alone to stand out. Give it a border or a shadow.

## Tints

<TintTable variants={['neutral', 'brand', 'success', 'warning', 'destructive', 'info']} />

#### A tint is a set, not a single color

Fill, border and text travel together: **Copy classes** gives you all three, e.g. `bg-tint-success-fill border-tint-success-border text-tint-success-text`. Each set pairs a light step of its scale with a darker text step, so every label stays above 6:1. Use tints for chips, badges and inline banners; never mix parts of two sets.

## Guidelines

<Guidelines>
  <Guideline>Every color is a step of a brand scale. Never use an off-scale value or a hardcoded hex.</Guideline>
  <Guideline>Prefer semantic roles over raw steps: `--muted-foreground`, not `--neutral-600`.</Guideline>
  <Guideline>Keep one primary (dark) action per region; other actions are secondary or ghost.</Guideline>
  <Guideline>Reserve coral for destructive actions and errors, so red always means danger.</Guideline>
  <Guideline>Links are neutral and always underlined: `text-link underline underline-offset-4`. The underline, not the color, shows they're clickable.</Guideline>
  <Guideline>Pair every status color with an icon or a label; color alone never carries meaning.</Guideline>
  <Guideline dont>Don't use green or coral for regular actions; green is identity, coral is danger.</Guideline>
  <Guideline dont>Don't remove a link's underline, and don't use blue for links; blue means information.</Guideline>
  <Guideline dont>Don't set small error text in `--coral-500`; use `--destructive-text` (`--coral-600`).</Guideline>
</Guidelines>
