## Usage

```css
/* Every color is a CSS custom property in styles/tokens.css.
   Prefer a semantic role; reach for a raw step only when no role fits. */
color: var(--muted-foreground);
background: var(--card);
border-color: var(--border);
```

```tsx
// The same roles as Tailwind utilities
<div className="border-border bg-card text-foreground" />
```

Click any swatch to copy its token.

## Core palettes

<ColorRamp scale="green" label="Green · primary brand tone" brandStep="500" />
<ColorRamp scale="neutral" label="Neutral · warm grey" />

#### Green is Matrix's color

Green carries identity: the logo, brand moments and tinted surfaces (the page itself is `--green-50`). Darker steps work for brand headings, lighter steps for backgrounds and hover. Green is not the action color; coral is.

## Action and highlight

<ColorRamp scale="coral" label="Coral · warm action, CTA" brandStep="500" />
<ColorRamp scale="gold" label="Gold · highlight, accent" brandStep="400" />

#### Coral is the action color

Coral marks what people can do: primary buttons, links and interactive highlights. Keep one dominant coral action per region. Brand coral (`--coral-500`) is 4.3:1 on a card, so small text and links use `--coral-600` (6.3:1).

## Status

<ColorRamp scale="teal" label="Teal · success" brandStep="500" />
<ColorRamp scale="blue" label="Blue · information, links" />

#### Status colors mean status

`teal` means success, connected or ready. `gold` means pending or needs attention. `coral` (the darker `--coral-700`) means failed or destructive. `blue` means informational or syncing. Always pair a status color with an icon or a label; color alone never carries meaning. Never use status colors for decoration.

#### Cards separate by edge, not fill

The page (`--green-50`) and card (`--neutral-100`) surfaces are only 1.03:1 apart, so a card never relies on its fill to stand out. Give it a border or a shadow.

## Tints

<TintTable variants={['neutral', 'brand', 'success', 'warning', 'destructive', 'info']} />

#### A tint is a set, not a single color

Fill, border and text travel together. Each set pairs a light step of its scale with a darker text step, so every label stays above 6:1. Use tints for chips, badges and inline banners; never mix parts of two sets.

## Open decisions

<Callout title="Waiting on a decision" type="warn">
  - **Focus ring.** Brand gold (`--gold-400`) is 1.9:1 on the page; a visible focus indicator needs 3:1. Options: a two-tone ring (gold with a dark inner ring), a darker gold step, or an exemption.
  - **Input border.** `--neutral-300` (Style library border) is 1.5:1: fine for dividers, too faint for input fields (3:1). `--neutral-500` is 3.6:1.
  - **Action vs destructive.** Both are coral. Destructive uses the darker `--coral-700` so delete never looks like "continue"; confirm this with the brand owner.
  - **Neutral 25.** In the Style library it is `#FFFFFF`, identical to Neutral 50.
</Callout>

## Guidelines

<Guidelines>
  <Guideline>Every color is a step of a brand scale. Never use an off-scale value or a hardcoded hex.</Guideline>
  <Guideline>Prefer semantic roles over raw steps: `--muted-foreground`, not `--neutral-600`.</Guideline>
  <Guideline>Keep one dominant coral action per region.</Guideline>
  <Guideline>Pair every status color with an icon or a label; color alone never carries meaning.</Guideline>
  <Guideline dont>Don't use green for actions; green is identity, coral is action.</Guideline>
  <Guideline dont>Don't set small text or links in `--coral-500`; use `--coral-600`.</Guideline>
</Guidelines>
