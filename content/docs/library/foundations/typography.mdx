---
title: Typography
description: Geist, five sizes, three weights. Hierarchy comes from weight and whitespace, not from ever-bigger text. Bricolage Grotesque is kept for brand moments.
---

## Usage

```tsx
// One size class, then weight and color classes on top; they stack freely.
<h2 className="text-heading">Agents and providers</h2>
<p className="text-ui">Connect a model to start chatting.</p>
<p className="text-ui-xs text-muted-foreground">Updated 2 minutes ago</p>
<span className="text-metric tabular-nums">2,481</span>
```

```css
/* Plain CSS: every size has a size + line-height pair */
.note {
  font-family: var(--font-family-sans);
  font-size: var(--type-ui-size);
  line-height: var(--type-ui-leading);
}
```

If you merge classes with shadcn's `cn()`, copy [`lib/utils.ts`](https://github.com/sahar-nouri-1/Matrix_design-system/blob/main/lib/utils.ts): it teaches the merge helper the Matrix sizes. Without it, `cn('text-ui', 'text-muted-foreground')` drops the size.

Reach for a class first; the raw tokens are there for custom CSS. `text-ui` (14/20) is the same as shadcn's `text-sm`, so shadcn components already sit on the scale.

## Fonts

<FontSpecimens />

The families are tokens (`--font-family-sans`, `--font-family-mono`, `--font-family-heading`) with system fallbacks, so you never write a font stack yourself. Load Geist, Geist Mono and Bricolage Grotesque with `next/font/google` (see `app/layout.tsx`).

## Tabular numbers

<TabularNumbers />

Proportional figures are the default. Add `tabular-nums` to columns of figures and to live counters, so digits don't shift as they change.

## Guidelines

<Guidelines>
  <Guideline>Never introduce a new size. The five product steps, two headings and two metric sizes are the whole product scale.</Guideline>
  <Guideline>Use the Tailwind class; it pairs each size with its line height. In plain CSS, always use the size and leading tokens together.</Guideline>
  <Guideline>Build hierarchy with weight and whitespace, not size jumps.</Guideline>
  <Guideline>Keep Bricolage for brand moments; product headings are Geist semibold.</Guideline>
  <Guideline>Add `tabular-nums` to columns of figures and to numbers that update live.</Guideline>
  <Guideline dont>Don't use Tailwind's default sizes (`text-base`, `text-lg`, `text-xl`) or arbitrary sizes like `text-[15px]`.</Guideline>
  <Guideline dont>Don't use `font-bold` in the product; 600 is the heaviest weight.</Guideline>
</Guidelines>
